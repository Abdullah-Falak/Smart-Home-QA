# Smart Home QA 🏠🔧

Smart Home QA is a lightweight, responsive web application built to simulate an e-commerce platform and service portal for smart home appliances. It allows users to browse smart devices, add items to a cart, and request professional Quality Assurance (QA) inspections or device repairs. 

This project was built focusing on frontend interactions, DOM manipulation, and state management, making it an excellent practice environment for manual and automated software testing.

## ✨ Features
* **E-Commerce Storefront:** Browse smart home appliances with dynamic stock status (In Stock / Out of Stock).
* **Shopping Cart Management:** Add items to the cart, automatically calculate totals, and process mock checkouts.
* **QA & Repair Portal:** Dedicated forms for users to submit Quality Assurance requests or report faulty devices for repair.
* **Authentication Simulation:** Mock login system required to process checkouts and submit service tickets.
* **Single Page Application (SPA) Routing:** Vanilla JavaScript handles seamless navigation between the Home, About, Shop, Services, and Cart pages without reloading.
* **Toast Notifications:** Real-time user feedback for actions like adding to the cart, form submissions, and login errors.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom styling, CSS Grid/Flexbox, and responsive design (No external libraries).
* **Vanilla JavaScript:** DOM manipulation, array filtering, and mock state management.
